What we would do next, credits, and declaration

What we would do next (in priority order)

  1. Self-healing server. Put the instance in an Auto Scaling group of one, built from a launch template that runs our bootstrap script, and keep MongoDB's data on its own EBS volume with daily snapshots. A dead server would be replaced automatically. (Our top Well-Architected gap.)
  2. Deploy from the repository automatically. A GitHub Actions workflow that, on a push to main, runs Session Manager's send-command to pull the code and restart the app — no more manual updates, and every change is recorded.
  3. Nightly answer-quality check. Run eval.py on 10 of the questions every night and publish the pass rate as a metric with an alarm, so a model change or a broken handbook shows up as a falling score.
  4. Close the last plain-HTTP hop. Have CloudFront add a secret header that nginx checks, or move to an HTTPS origin, so traffic between CloudFront and the server is protected too.
  5. Switch the server off when nobody uses it. Stop the instance overnight with a scheduled job (and start it in the morning) to cut compute cost by about a third.
